# Digital Seva — Online Application Assistance Portal

A modern, fast, and accessible citizen assistance website built to guide and support citizens with online applications for government and public services.

## 🌟 Confirmed Services
- **PAN Card** — New Application & Corrections
- **Voter ID** — New Registration & Corrections
- **Aadhaar Address Correction Assistance**
- **Indian Passport** — Fresh Application & Corrections/Renewal
- **Income Certificate Application Assistance**
- **Caste Certificate Application Assistance**
- **Scholarship Applications** (State & National Portals)
- **More Online Applications** (Citizen & Public Portals)

## 🛠️ Features & Architecture
- **Interactive Light & Dark Themes**: System-aware theme toggle with instant persistence via `localStorage`.
- **Custom Cursor & Micro-Interactions**: Smooth cursor tracking and hover scaling on interactive elements.
- **Magnetic Buttons & 3D Tilt**: Physics-based magnetic hover effect on buttons and responsive 3D card tilt.
- **GSAP & ScrollTrigger Animations**: Fluid scroll-triggered section entrances and floating gradient backdrops.
- **Responsive Layout**: Designed for seamless accessibility across mobile, tablet, and desktop viewports.
- **Fast & Zero-Build**: Built with standard vanilla HTML5, CSS3, and modern JavaScript.

## 📦 Running Locally
To preview or test the website locally, serve the project folder using any static HTTP server:

```bash
# Using Python 3
python3 -m http.server 8000

# Or using Node.js
npx serve -l 8000
```
Then visit `http://localhost:8000` in your web browser.
